把别人爆款视频的文案丢给 AI，它会告诉你开头为什么留人、整条怎么分段、结尾怎么骗你留言。再用同样的结构，帮你写自己的脚本。下面 3 段 prompt 按顺序用。

复制爆款文案→拆一条→丢 5 条找规律→写你的脚本
0

先把爆款文案拿出来

  • 找爆款：在你的领域里，找播放量明显比账号平均高很多的那几条
  • 复制文案：IG / 小红书的 caption 长按就能复制；视频里讲的话，看字幕抄下来就好
  • 用什么 AI：Claude 或 ChatGPT 都可以，视频里我用的是 Claude
1

拆解一条爆款

开一个新对话，贴上这段，再把文案贴在最后面：

拆解单条爆款
我会贴给你一条短视频的文案或字幕。请帮我拆解：
1. 开头钩子：前3秒说了什么？为什么让人停下来？
2. 结构：整条视频分成几段，每段的作用是什么？
3. 留人技巧：中间用了哪些方法让人继续看下去？
4. 结尾：怎么引导观众留言、收藏或关注？
5. 可以学的地方：如果我要做同类型内容，最值得模仿的3个点是什么？

请用简单的中文回答，每一点都举出原文里的句子做例子。

文案如下：
（把爆款视频的文案贴在这里）

叫它「举出原文里的句子做例子」很重要，不然它只会讲空泛的道理。

2

一次丢 5 条，找共同规律

同一个对话继续，把 5 条同领域的爆款文案一起贴进去：

找爆款共同规律
以下是同一个领域里5条播放量很高的视频文案。请帮我找出：
1. 它们开头的共同套路
2. 结构上的共同规律
3. 每隔几秒会出现一个新的信息点或转折
4. 结尾都怎么引导互动
5. 总结成一个我可以重复使用的「爆款模板」

文案1：
文案2：
文案3：
文案4：
文案5：

一条爆款可能是运气，5 条都用同一招，就是规律。这一步最值钱。

3

用同样的结构写你的脚本

还是同一个对话，把括号里的主题和观众换成你自己的：

用爆款模板写新脚本
请用上面找出来的爆款模板，帮我写一条30到40秒的短视频脚本。
主题：（写你要拍的主题）
我的观众：（例如：想学AI的上班族）
要求：
- 开头3秒先给结果或冲突，不要铺垫
- 每5到7秒抛出一个新的好处或转折
- 结尾引导观众留言
- 口语化，像朋友在讲话
请分成「画面」和「旁白」两栏写出来。

用完不要跟我老板讲很好用，不然他又叫我加班。
